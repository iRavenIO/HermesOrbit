# HermesMob

Native iOS control plane for Hermes Agent.

## Purpose

HermesMob is intended to become a premium mobile product for operating Hermes Agent from iPhone and iPad with:

- full Hermes web-dashboard parity in the MVP
- native mobile interaction patterns
- self-hosted deployment first
- a clean path to managed hosted Hermes later
- App Store-safe branding and product positioning

## Repository layout

- `docs/PRODUCT_BLUEPRINT.md` — product blueprint, MVP scope, UX, architecture, and rollout plan
- `docs/BUSINESS_PLAN.md` — market thesis, positioning, pricing, GTM, and business model
- `docs/APP_STORE_NAMING_RESEARCH.md` — App Store naming constraints and candidate analysis
- `ios/` — iOS project scaffold and implementation-facing structure
